Install guide

This guide walks through getting the system running on a clean machine, all the way to launching the apps. Pick your platform below.

Before you start

The system includes three GUI apps, imageAligner, segmentationApp and singlePlantAnalysis, each with its own run.py. Installer scripts set up conda environments with platform-specific handling.

Prerequisites

01

Install WSL2 + Ubuntu

In PowerShell as Administrator. If WSL is already installed, add Ubuntu with wsl --install -d Ubuntu. Windows 11 includes WSLg; on Windows 10, run wsl --update.

POWERSHELL
wsl --install
02

GPU setup (NVIDIA only)

Install the Windows-side NVIDIA driver from nvidia.com, then verify with nvidia-smi.

⚠ WARNING Do not install a separate NVIDIA Linux driver inside WSL.
03

Install Miniconda

Run the three download-and-init commands in your WSL terminal.

[Miniconda commands from current guide]

Install

04

Clone and run the installer

WSL · BASH
git clone https://github.com/calvinyong1/ArabidopsisAnalysisV2.git
cd ArabidopsisAnalysisV2
bash installer_conda_wsl.sh

The script detects your GPU, installs system libraries, asks for an install directory (default ~/.local/chronoroot), and lets you choose a Full Node (GPU + segmentation) or Lite Node (analysis only).

Troubleshooting

GUI windows don't appear / empty $DISPLAY

Usually WSL1 instead of WSL2. Check your WSL version and run wsl --update.

"no Qt platform plugin could be initialized"
PyTorch can't see CUDA
Shortcuts weren't created

Linux

Uses installer_conda_linux.sh, which works like the Windows installer and creates .desktop launchers for your app menu.

bash installer_conda_linux.sh

macOS

macOS installs in place, running from the folder you clone into. On Apple Silicon, segmentation uses the MPS backend automatically.

NOTE Don't delete this clone afterward. It's the copy the app runs from. 
xcode-select --install
bash installer_conda_mac.sh

Updating

Re-run the installer for your platform. It detects the existing install, pulls the latest changes, and updates the environment.
